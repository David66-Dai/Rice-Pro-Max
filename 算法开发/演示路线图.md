## 演示点详情

### 演示点 1：ResNet18 迁移学习

**文件：** `算法开发/叶害算法开发/train.py`
**定位：** 搜索 `演示点1`

**话术：**  
"叶害分类我们选用 ResNet18。它只有 18 层，非常轻量，残差连接结构能有效缓解梯度消失。核心原理是——用 ImageNet 上预训练好的权重初始化，让模型自带'视觉理解能力'，然后在小数据集上微调。"

```python
from torchvision import models

# 加载 ImageNet 预训练权重
w = models.ResNet18_Weights.IMAGENET1K_V1
model = models.resnet18(weights=w)
```

model.fc = nn.Linear(model.fc.in_features, 4)

### 演示点 3：数据增强策略

**文件：** `算法开发/叶害算法开发/train.py`
**定位：** 搜索 `演示点3`

**话术：**  
"农业场景的难点在于——光照、角度、距离变化巨大，但数据量有限。我们用数据增强'虚拟扩充'训练集。"

```python
from torchvision import transforms

train_tf = transforms.Compose([
    transforms.Resize((256, 256)),                  # 统一缩放
    transforms.RandomResizedCrop(224, scale=(0.8, 1.0)),  # 模拟不同距离
    transforms.RandomHorizontalFlip(),               # 模拟左右朝向
    transforms.ColorJitter(0.15, 0.15, 0.1, 0.05),  # 模拟光照变化
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])
```

**对比：** 验证集不做增强，只做 `Resize → ToTensor → Normalize`

### 演示点 4：类别加权

**文件：** `算法开发/叶害算法开发/train.py`
**定位：** 搜索 `演示点4`

**话术：**  
"四类样本数量不均——健康叶最多，东格鲁病毒最少。如果直接训练，模型会倾向于预测'健康'。解决方案是类别加权交叉熵——样本少的类别给大权重。"

```python
# 统计每类样本数
counts = torch.zeros(num_classes)
for _, y in train_subset:
    counts[y] += 1

# 核心公式：权重 = 总样本数 / (类别数 × 该类样本数)
weights = counts.sum() / (num_classes * counts)

# 带入损失函数
criterion = nn.CrossEntropyLoss(weight=weights)
```

### 演示点 5：核心训练循环

**文件：** `算法开发/叶害算法开发/train.py`
**定位：** 搜索 `演示点5`

**话术：**  
"这是最经典的三步走——梯度清零、反向传播、参数更新。每个 batch 执行一次，整个数据集跑完叫一个 epoch。"

```python
for epoch in range(epochs):
    model.train()
    for images, labels in train_loader:
        images, labels = images.to(device), labels.to(device)
        
        optimizer.zero_grad()        # ① 清除上轮梯度
        outputs = model(images)      # ② 前向传播
        loss = criterion(outputs, labels)
        loss.backward()              # ③ 反向传播
        optimizer.step()             # ④ 更新参数
```

### 演示点 6：YOLO11x 一行训练

**文件：** `算法开发/虫害算法开发/train.py`
**定位：** 搜索 `演示点6`

**话术：**  
"传统目标检测框架写一个训练脚本要上百行。YOLO11x 的 API 设计极简——加载预训练权重，配置参数，一行 `.train()` 全部搞定。它内置了 C2f 跨阶段连接、特征金字塔和自动锚框计算。"

```python
from ultralytics import YOLO

model = YOLO("yolo11x.pt")
model.train(
    data="data/dataset.yaml",   # 数据集配置
    epochs=100,                 # 训练轮数
    imgsz=640,                  # 输入分辨率
    batch=14,                   # 批次大小
    patience=20,                # 早停耐心值
    device=0,                   # GPU 编号
)
```

### 演示点 8：推理核心三步骤

**文件：** `算法开发/叶害算法开发/predict.py`
**定位：** 搜索 `演示点8`

**话术：**  
"预处理完的图片送入模型，三步得到结果。"

```python
img = Image.open("test.jpg").convert("RGB")
x = tfm(img).unsqueeze(0).to(device)  # 加 batch 维度

with torch.no_grad():                  # 关闭梯度，省显存
    logits = model(x)                  # ① 前向传播 → 原始分数
    prob = torch.softmax(logits, dim=1)[0]  # ② softmax → 概率
    pred = int(prob.argmax().item())   # ③ argmax → 最高概率类别
```

### 演示点 9：YOLO 一行推理

**文件：** `算法开发/虫害算法开发/predict.py`
**定位：** 搜索 `演示点9`

**话术：**  
"虫害检测同样一行代码完成——传入图片路径和置信度阈值，直接得到所有检测框的坐标、类别和置信度。"

```python
model = YOLO("best.pt")
results = model.predict(source="test.jpg", conf=0.25)

# 遍历检测框
for r in results:
    for box in r.boxes:
        cls_id = int(box.cls[0])        # 类别 ID
        conf = float(box.conf[0])       # 置信度
        x1, y1, x2, y2 = box.xyxy[0]   # 边界框坐标
```

## 演讲技巧建议

| 技巧 | 说明 |
|------|------|
| **先跑再讲** | 每个演示点提前在 IDE 中打开，光标停在关键行上 |
| **边敲边讲** | 缓慢敲核心 1~2 行，解释参数含义，不要太快 |
| **对比法** | YOLO 训练强调"一行代码 vs 传统上百行"的反差 |
| **视觉辅助** | 提前准备好推理前后的对比图（原始 → 标注结果） |
| **避开陷阱** | 不要在演示时跑训练（太慢），只展示代码结构 |
